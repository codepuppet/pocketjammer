What Pocket Jammer does

Pocket Jammer helps you build beats fast. Tap drum pads to trigger sounds, capture your performance into a 16-step sequencer loop.

iOS 26+ SwiftUI + AVFoundation Offline / No backend WAV export

Key features

  • Pad performance: instant, responsive drum pads.
  • Step sequencer: 16 steps per bar with looping playback.
  • Live record: enable Record to write pad taps into the current step as you play.
  • Patterns: multiple patterns (A/B/C) with swipe switching.
  • Export: offline-rendered WAV file you can share anywhere.

Quick Start

  1. Tap Play to start the loop.
  2. Tap a pad to hear a sound immediately.
  3. Select an instrument, then tap steps in the lane to program hits.
  4. Enable Record, then tap pads while playing to write hits into the loop.
  5. Swipe left/right to switch patterns (A/B/C).

Clearing steps

In the step lane, use the … menu (or long-press the lane) to clear:

  • Clear Pad — clears steps for the selected instrument
  • Clear Pattern — clears all instruments in the current pattern

Export

Tap Export to render the current pattern to a WAV file offline (not realtime) and volume settings. Then share it using the iOS share sheet.

Note: On iOS Simulator, the share sheet may appear empty due to simulator limitations. Exported files still generate correctly.
